💻 Horizontal Image Gallery Scroll

This is a modern, responsive web-based horizontal image gallery that allows users to scroll through image sets using navigation buttons or mouse wheel. Built with a clean, minimal UI and smooth animations. 🎨
🔥 Features:

    Smooth horizontal scrolling for seamless navigation

    Scroll using mouse wheel or left/right arrow buttons

    Grayscale-to-color image transition on hover

    Responsive grid layout using Flexbox and CSS Grid

    Hidden scrollbars for a cleaner look

    Modern UI with Poppins font and dark theme

📁 Tech Stack:

    HTML

    CSS

    JavaScript (Vanilla)

🚀 How to Use:

    Scroll using your mouse wheel or the left/right arrow buttons.

    Hover over an image to reveal it in full color with a zoom effect.

    Easily explore the full gallery in a smooth, user-friendly interface.
